# Railway Accident Severity Prediction

## Project Description
This project predicts the severity level of railway accidents using accident-related data and a Decision Tree Classifier.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Decision Tree Classifier

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Encoding
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Severity Prediction

## Severity Levels
- Low: 0–10 casualties
- Medium: 11–50 casualties
- High: More than 50 casualties

## Model
Decision Tree Classifier

## Files
- `Railway_Accident_Severity_Prediction.ipynb` – Project notebook containing the complete implementation.
